# Своя «Моя волна» для Spotify: как я сделал персональное радио, когда Spotify закрыл API

> Черновик статьи для Habr. Можно публиковать как есть или сократить.

Привет, Хабр.

Я ушёл с Яндекс.Музыки на Spotify и почти сразу упёрся в две вещи: реклама (лечится SpotX)
и отсутствие нормальной «Моей волны». Daylist выдаёт не то, что я слушаю, а «радио» по
плейлисту — это просто shuffle с редкими вкраплениями. В итоге я собрал **spotwave** —
бесконечное персональное радио прямо внутри клиента Spotify.

## Почему «просто взять Web API» не получилось

С февраля 2026 Spotify ужесточил правила:

- владелец приложения в development mode обязан иметь Premium;
- extended quota mode выдают только юрлицам;
- `/recommendations`, `/audio-features`, related artists и top tracks для новых приложений
  недоступны.

Для личного проекта на free-аккаунте официальный путь закрыт. Значит, остаётся то же, чем
пользуется сам интерфейс Spotify: внутренние методы клиента.

Spotify desktop — это CEF-приложение, а Spicetify даёт к нему доступ: `Spicetify.Platform`,
`Spicetify.Player`, GraphQL-обёртку. Никаких токенов и OAuth — приложение работает от сессии
самого клиента, как встроенная вкладка.

## Как устроен рекомендательный движок

Главная находка: клиент умеет отдавать рекомендации **по контексту плейлиста**:

```js
PlaylistAPI.getRecommendedTracks(contextUri, skipIds, limit, {
  decorateWithBpmAndKey: true
})
```

Это тот же движок, который стоит за «Enhance» и похожими треками. Вместе с треками он
возвращает BPM и тональность — единственная доступная замена закрытым audio features.

Дальше:

1. **Лайки** — это служебный плейлист, поэтому «мой микс» — просто ещё один контекст.
2. Для волны по треку/артисту/альбому создаётся временный плейлист-семя.
3. Кандидаты фильтруются: баны, «только новое», BPM-диапазон настроения, длинные треки,
   slowed/remix/karaoke.
4. Ранжирование: аффинити артиста (дослушивания + лайки − скипы), свежесть, новизна,
   немного случайности.
5. Выбор: не больше N треков одного артиста и двух с одного альбома, без повторов подряд.

## Три технические грабли

**Очередь врёт.** Наивный вариант «включить первый трек и добавить остальные в очередь»
ломается: внутренний `addToQueue` теряет элементы в момент смены контекста, и в итоге играет
один трек, а кнопка «далее» ничего не делает. Решение — писать волну в служебный плейлист
`Волна · Live` и запускать его как контекст. Тогда штатные next/prev/shuffle работают.

**Скипы надо ловить всегда.** Вкладку Волны никто не держит открытой. Поэтому трекинг живёт
в отдельном extension, который грузится при старте клиента: `songchange` + `onprogress`,
события складываются в `localStorage`, приложение их «переваривает». Дослушал — плюс,
скипнул на 20-й секунде — минус.

**«Только новое» — это не только URI.** Ремастеры, переиздания и «(Slowed)» версии имеют
другие URI, но тот же трек. Приходится сравнивать ещё и нормализованные «артист + название».

## Что умеет

- Волна по лайкам, плейлисту, треку, артисту, альбому.
- «Только новое»: исключает всё из плейлистов, лайков и недавнего.
- Настроения по BPM: спокойное / грустное / среднее / энергичное, плюс медленное, фокус и быстрое в подробном режиме.
- Два режима настроек: «Просто» и «Подробно».
- Пресеты (Утро, Грусть, Фокус, Вечер, Дорога) и обмен своими через код `SW1.`.
- Утренняя волна по расписанию: в заданное время появляется кнопка, музыка сама не включается.
- Автопродление, когда волна заканчивается.
- Обучение на скипах и лайках, ручные «убрать трек» и «больше не этот артист».
- Причина выбора у каждого трека.
- Статистика: прослушивания, скипы, топ-артисты, распределение по дням и часам.
- Экспорт профиля в JSON и скробблинг в ListenBrainz (опционально).
- Двуязычный интерфейс (RU/EN) и нативная верстка в стиле Spotify.

## Установка

Нужны Spotify desktop и Spicetify.

```powershell
# Windows
iwr -useb https://raw.githubusercontent.com/WhyTunesWorkspace/spotwave/main/scripts/install.ps1 | iex
```

```bash
# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/WhyTunesWorkspace/spotwave/main/scripts/install.sh | bash
```

Либо через **Spicetify Marketplace → Apps**: найдите spotwave в каталоге (карточка ведёт
в репозиторий) и установите тем же скриптом выше.

После установки в левом верхнем углу Spotify появляется иконка с волной.

Приложение есть в **Spicetify Marketplace → Apps** (карточка ведёт на репозиторий), а также
ставится одной строкой скриптом выше.

Репозиторий: https://github.com/WhyTunesWorkspace/spotwave

## Честные ограничения

- Это модификация клиента. Как и SpotX/Spicetify, она формально расходится с ToS Spotify.
  Использование личное, ничего не скачивается и не раздаётся.
- После крупных обновлений Spotify внутренние методы могут поменяться; установщик нужно
  запускать повторно.
- Нет audio features — «энергия» считается по BPM, это приближение.
- Скробблинг — только ListenBrainz (Last.fm требует отдельной OAuth-сессии).
